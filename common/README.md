# 공통 목업 도구

저장소 이름은 `html`, 프로젝트 폴더는 `gfair_cs`를 사용한다.

- 공통 도구: `common/include/`의 로그인, Description, 번호 라벨과 댓글 기능.
- 공통 스타일: `common/css/`.
- 공통 서버 주소: `common/config.js`의 `server` 한 곳에서 관리.
- 프로젝트: `gfair_cs/` 아래 화면·데이터·업무별 스크립트·스타일.
- 공개 프로젝트 목록: 저장소 루트 `index.html`.

새 프로젝트를 추가할 때:

1. 새 프로젝트 폴더와 화면을 추가하고 `<body data-project="프로젝트ID" ...>`를 지정한다.
2. 공통 도구는 기존 프로젝트의 footer.js와 같이 `common/`에서 불러온다. 공통 스크립트를 프로젝트 안에 복제하지 않는다.
3. 공동작업 서버의 `server/projects.mjs` 등록부에 프로젝트 ID, 제목, 권한 확인 저장소, 복귀 URL을 추가한다. 임의의 외부 복귀 URL은 받지 않는다.
4. 루트 프로젝트 목록에 링크를 추가한다.

GitHub App과 저장 서버는 그대로 공유한다. 저장소를 달리하는 프로젝트를 등록한다면 기존 GitHub App을 해당 저장소에도 설치한다.

설명·번호는 프로젝트와 화면 ID를 함께 기준으로 저장한다. 기존 설명과 댓글은 `gfair_cs`에 유지한다. 다른 프로젝트의 화면 ID가 같아도 데이터가 섞이지 않는다.
