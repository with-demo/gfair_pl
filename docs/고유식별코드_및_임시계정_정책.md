# 참가자 고유식별코드 및 임시계정 정책

확정일: 2026-10-21 (한국 시간)
적용 대상: 국내 바이어, 해외 바이어, 통역원 및 운영사 계정

## 1. 참가자 고유식별코드

고유식별코드는 참가자의 내부 식별·연도별 이력 연결에 사용한다. 행사별 임시 로그인 ID와는 서로 다른 값이다.

| 대상 | 규칙 | 예시 |
| --- | --- | --- |
| 국내 바이어 | `K` + 행사연도 4자리 + 4자리 일련번호 | `K20270001` |
| 해외 바이어 | `F` + 행사연도 4자리 + 4자리 일련번호 | `F20270001` |
| 통역원 | `I` + 행사연도 4자리 + 4자리 일련번호 | `I20270001` |

일련번호는 `0001`부터 네 자리로 표현한다. 연도별 참가 이력은 이 고유식별코드를 기준으로 이어서 조회한다.

## 2. 행사별 임시계정 ID

임시계정 ID는 로그인에 사용하는 행사별 계정이며, 고유식별코드와 구분한다.

| 대상 | 규칙 | 예시 |
| --- | --- | --- |
| 국내 바이어 | `GK` + 행사연도 뒤 2자리 + 4자리 일련번호 | `GK270001` |
| 해외 바이어 | `GF` + 행사연도 뒤 2자리 + 4자리 일련번호 | `GF270001` |
| 통역원 | `GI` + 행사연도 뒤 2자리 + 4자리 일련번호 | `GI270001` |

운영사 임시 ID는 자동 규칙으로 생성하지 않는다. 관리자가 임의로 ID를 지정해 등록한다.

## 3. 임시비밀번호

운영사·바이어·통역원 계정에 공통 적용한다. 영문 대문자 1자와 숫자 6자리로 구성하며, 임시비밀번호는 무작위로 발급한다. 예: `A327851`.

## 4. 화면·데이터 적용 기준

- 참가자 고유식별코드는 여러 해에 걸친 동일 참가자의 이력을 연결하는 키로 표시한다.
- 행사별 임시계정 이력에는 해당 연도의 임시 ID와 발급 상태를 표시한다.
- 임시비밀번호는 계정별 발급값이므로 화면에서 기본 마스킹하고, 실제 비밀번호·개인 계정 정보를 목업 예시 데이터에 넣지 않는다.
- 임시계정 ID는 행사 연도별로 달라질 수 있으며, 고유식별코드와 혼용하지 않는다.
- 예시 형식은 위 규칙을 설명하기 위한 값이다. 실제 계정 발급·저장·전달 정책은 별도 연동 시 적용한다.

## 5. 추가 확정이 필요한 세부 규칙

- 네 자리 일련번호의 중복 방지 범위, 번호 소진 시 처리, 삭제된 번호의 재사용 여부는 이 요청에서 지정되지 않았으므로 임의로 정책을 확정하지 않는다.
- 임시비밀번호의 재발급·초기화·전달 절차는 지정되지 않았으므로 별도 협의 대상으로 둔다.
